# CertificateDemo

Demo PHP projekta za delo z avtentikacijo in digitalnimi certifikati.

## Vsebina

- `client/` – odjemalski del aplikacije
- `server/` – API in strežniška logika
- `certs/` – certifikati za testiranje
- `_server/` – dodatni strežniški primer
- `logs/` – lokalni logi

## Zahteve

- XAMPP
- PHP
- Apache
- MySQL
